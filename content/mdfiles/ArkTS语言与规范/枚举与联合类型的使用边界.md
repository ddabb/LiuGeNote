# 枚举、联合类型与字面量类型：ArkTS 的取值约束三件套

「这个字段只能是一组固定值之一」——星期几、主题色、排序方式。ArkTS 里有三种写法，各有边界。

## enum：命名的常量集合

```typescript
enum SortOrder {
  ByTime,      // 0
  ByWords,     // 1
  ByTitle      // 2
}

let order: SortOrder = SortOrder.ByTime;
```

注意事项：

1. **枚举名与成员名必须与 SDK 完全一致**（大小写敏感）：`ButtonType.CAPSULE`、`TouchType.Up`、`LineCapStyle.Round`——拼错直接编译错误，这是好事；
2. **`.values()` 在 ArkTS 上不可用**——遍历枚举值需要自己维护一份数组常量；
3. 枚举成员传参时类型是枚举而非 number，**不要传字符串字面量到枚举参数位**。

## 字符串字面量联合类型：轻量取值约束

```typescript
type ThemeMode = 'light' | 'dark' | 'sepia';

let mode: ThemeMode = 'dark';       // ✅ 只能是这三个值
// mode = 'blue';                   // ❌ 编译错误
```

适合**纯展示、不进 SDK 调用**的内部取值。比 enum 轻（无运行时对象），代价是没有反向查找（按值取名要自己 switch）。

## 常量集合：最朴素也最稳

```typescript
class Categories {
  static readonly LANGUAGE: string = 'ArkTS语言与规范';
  static readonly NAVIGATION: string = '页面与导航';
}
```

数据驱动的场景（分类名来自 JSON 数据），枚举反而碍事——**运行时数据和编译期枚举是两个世界**，此时用常量对齐拼写即可，匹配用 `===`。

## 选型决策

| 场景 | 推荐 |
|---|---|
| SDK API 参数（对齐系统枚举） | 直接用 SDK 的 enum |
| 内部状态机（有限值 + switch 分发） | enum |
| 简单二/三值开关 | 字面量联合类型 |
| 值来自外部数据（JSON/DB） | 字符串常量 + `===` |

## switch 分发要与类型联动

```typescript
function applyMode(mode: ThemeMode): void {
  switch (mode) {
    case 'light':
      this.bg = '#FFFFFF';
      break;
    case 'dark':
      this.bg = '#1C1C1E';
      break;
    case 'sepia':
      this.bg = '#F4ECD8';
      break;
  }
}
```

字面量联合类型 + switch 的组合里，漏分支在严格模式下有「未覆盖」提示；改用对象映射（`Record<ThemeMode, ResourceColor>`）可以一行取值，但分支逻辑复杂时不如有 switch 直白。

## 踩坑记录

1. 数字枚举的**自增**从上一个成员 +1 开始，中间插值会整体偏移——序列化存储过的枚举值要警惕；
2. 枚举与字符串比较 `SortOrder.ByTime === 'ByTime'` 恒 false（数字枚举），别混比；
3. 外部数据「看起来像枚举」也要先校验：`JSON.parse` 出来的值可能是任意串，进枚举前 `typeof` + 白名单判断。

## 一句话总结

**对齐 SDK 用 enum，内部约束用字面量联合，外部数据用常量加校验**——三件套各管一段，别混着用。
