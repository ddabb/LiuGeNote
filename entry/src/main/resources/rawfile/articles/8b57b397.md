
# Canvas 自定义绘制入门：从画布到像素

组件堆不出来的视觉效果——环形进度、签名板、图表——交给 Canvas 逐像素画。

## 画布的初始化

```typescript
private settings: RenderingContextSettings = new RenderingContextSettings(true);   // true 开启抗锯齿
private context: CanvasRenderingContext2D = new CanvasRenderingContext2D(this.settings);

build() {
  Canvas(this.context)
    .width('100%')
    .height(240)
    .onReady(() => {
      this.drawProgress(0.68);       // 画布就绪才能画，onReady 是起点
    })
}
```

**onReady 是关键**：画布尺寸就绪后才能拿到真实宽高，之前画了也是 0。

## 基本绘制 API

```typescript
// 矩形
this.context.fillStyle = '#F4F4F5';
this.context.fillRect(0, 0, width, height);

// 圆形
this.context.beginPath();
this.context.arc(cx, cy, radius, 0, Math.PI * 2);
this.context.fillStyle = '#8A2BE2';
this.context.fill();

// 线条
this.context.beginPath();
this.context.moveTo(x1, y1);
this.context.lineTo(x2, y2);
this.context.strokeStyle = '#999999';
this.context.lineWidth = 2;
this.context.stroke();

// 文本
this.context.font = 'bold 28px sans-serif';
this.context.fillStyle = '#1C1C1E';
this.context.fillText('68%', cx, cy);
```

API 是 Web Canvas 的同款模型：`beginPath` 起笔 → 一串路径指令 → `fill`/`stroke` 落笔。

## 实战：环形进度

```typescript
drawProgress(percent: number): void {
  const w: number = this.context.width;
  const h: number = this.context.height;
  const cx: number = w / 2;
  const cy: number = h / 2;
  const r: number = Math.min(w, h) / 2 - 12;

  this.context.clearRect(0, 0, w, h);                  // 先清屏

  // 底环
  this.context.beginPath();
  this.context.arc(cx, cy, r, 0, Math.PI * 2);
  this.context.strokeStyle = '#E5E5EA';
  this.context.lineWidth = 10;
  this.context.stroke();

  // 进度弧：从顶部(-90°)顺时针
  this.context.beginPath();
  this.context.arc(cx, cy, r, -Math.PI / 2, -Math.PI / 2 + Math.PI * 2 * percent);
  this.context.strokeStyle = '#8A2BE2';
  this.context.lineWidth = 10;
  this.context.lineCap = LineCapStyle.Round;           // 圆头更精致
  this.context.stroke();
}
```

清屏 → 底图 → 进度层，**每帧全量重画**是 Canvas 的常规节奏。

## 触摸交互：让画布响应手指

```typescript
Canvas(this.context)
  .onTouch((event: TouchEvent) => {
    for (const touch of event.touches) {               // touches: TouchObject[]
      const x: number = touch.x;                       // 触点坐标
      const y: number = touch.y;
      this.context.fillRect(x - 2, y - 2, 4, 4);       // 签名板：点哪画哪
    }
  })
```

签名板、刮刮卡、图表取值——都是「onTouch 拿坐标 + 坐标驱动绘制」的组合。

## OffscreenCanvas：先离屏画好再贴

高频重绘（动画图表）在**离屏画布**上画完，再一次贴到可见画布，减少主画布抖动：

```typescript
private off: OffscreenCanvas = new OffscreenCanvas(600, 400);
// 复杂图层画在 off 上，再 drawImage 到主画布
```

## 什么时候不用 Canvas

| 需求 | 更优方案 |
|---|---|
| 环形进度（有现成组件） | `Progress` 组件 |
| 线性图表 | 组件库或简单 Row 柱 |
| 简单几何装饰 | Stack + borderRadius |
| 自由绘制/像素级控制 | Canvas ✓ |

Canvas 是最后手段：**组件能表达的就别手绘**——可访问性、事件、适配全部要自己造。

## 一句话总结

**onReady 起笔、beginPath 落笔、clearRect 每帧清屏**——记住三拍子，Canvas 就是你的像素画板。
