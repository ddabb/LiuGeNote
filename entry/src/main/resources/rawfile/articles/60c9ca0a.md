
# 手势系统：PanGesture 拖拽与滑动交互实践

按钮点击之外的一切「手跟屏幕」的交互——拖拽、侧滑删除、下拉刷新——都归手势系统管。

## PanGesture：平移手势

```typescript
@State posX: number = 0;
@State posY: number = 0;

Stack() {
  Circle({ width: 64, height: 64 })
    .fill('#8A2BE2')
    .translate({ x: this.posX, y: this.posY })
    .gesture(
      PanGesture({ fingers: 1, distance: 5 })      // 单指、5vp 触发阈值
        .onActionStart((event: GestureEvent) => {
          console.info('拖拽开始');
        })
        .onActionUpdate((event: GestureEvent) => {
          // offsetX/Y 是从手势开始的累计偏移，增量驱动状态
          this.posX += event.offsetX;
          this.posY += event.offsetY;
        })
        .onActionEnd(() => {
          console.info('拖拽结束');
        })
    )
}
```

要点：

- `distance: 5` 触发阈值：太小会误触（点按被识别成拖），太大跟手延迟；
- `onActionUpdate` 里**累加增量**（`+=`），而非直接赋绝对值；
- 位置变化用 `.translate()` 而不是改布局属性——translate 不触发重排，性能好。

## 手势的组合

```typescript
.gesture(
  GestureGroup(GestureMode.Exclusive,      // 互斥：命中一个取消其余
    PanGesture({ direction: PanDirection.Horizontal }),   // 横滑
    TapGesture()                                           // 或点按
  )
)
```

| 模式 | 语义 |
|---|---|
| `GestureMode.Exclusive` | 互斥，只响应一个 |
| `GestureMode.Parallel` | 并行，同时识别（点按 + 长按并存） |

## 手势与滚动的冲突

List 里给条目加横滑删除，会与 List 纵向滚动打架：

1. **方向隔离**：`PanGesture({ direction: PanDirection.Horizontal })` 只声明横滑，纵向交给 List；
2. **阈值让位**：手势 5vp 阈值 + 方向限制，先横滑识别成功则 List 不滚动；
3. 嵌套同方向手势才需要 `.priorityGesture()`（子优先）或 `.parallelGesture()` 抢仲裁。

## 滑动删除条目的骨架

```typescript
ListItem() {
  Row() {
    Text('条目内容').layoutWeight(1)
    Button('删除')
      .backgroundColor('#E03030')
      .translate({ x: this.deleteReveal })   // 删除按钮从右侧滑出
  }
  .gesture(
    PanGesture({ fingers: 1, direction: PanDirection.Horizontal, distance: 8 })
      .onActionUpdate((event: GestureEvent) => {
        this.deleteReveal = Math.max(-80, Math.min(0, this.deleteReveal + event.offsetX));
      })
      .onActionEnd(() => {
        // 越过一半吸附展开，否则弹回
        this.deleteReveal = this.deleteReveal < -40 ? -80 : 0;
      })
  )
}
```

**边界钳制**（Math.min/Math.max）是拖拽跟手的关键——没有边界的拖拽会把元素拖出屏幕。

## 手势的三层 API

| 层级 | 写法 | 用途 |
|---|---|---|
| 组件快捷手势 | `.onClick()` / `.onLongPress()` | 点、长按 |
| 单手势 | `.gesture(PanGesture())` | 拖、捏合、旋转 |
| 组合仲裁 | `GestureGroup` / `.priorityGesture` | 多手势并存/冲突 |

## 踩坑记录

1. `onActionUpdate` 里直接赋 `event.offsetX`（非增量累加）：手势一停元素跳回；
2. 忘记方向限制：纵向 List 里条目横滑手势会把 List 滚动抢走；
3. 拖拽元素用了 `.margin()` 跟手：margin 触发重排掉帧，改 `.translate()`；
4. `fingers` 写 2 但测试单指：多指手势单指不触发。

## 一句话总结

PanGesture 三件事：**增量累加、方向隔离、边界钳制**。做到这三点，拖拽交互就跟手了。
